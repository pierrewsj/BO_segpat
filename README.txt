BO DIGITAL GSP — VERSÃO 25.0.0
ASSISTENTE OPERACIONAL DE RELATO E PROVIDÊNCIAS

Principais recursos:
- Usa somente dados preenchidos no próprio boletim.
- Funciona offline e não depende de IA externa.
- Identifica o perfil da ocorrência.
- Confere informações obrigatórias e recomendadas.
- Busca pessoas, veículos, materiais, MVM/NF, fornecedor, desenho, código, quantidade e observações.
- Gera relato cronológico padronizado.
- Organiza as providências e áreas acionadas.
- Marca o relato como desatualizado quando algum dado usado no texto é alterado.
- Mantém edição manual e exige revisão do vigilante.
- Mantém responsividade para smartphone, tablet e computador.
- Mantém a logo Stellantis branca na tela de login.

API Google Apps Script compatível: 6.1.0 / compact-u.
O Google Apps Script não precisa ser alterado para usar o assistente.
